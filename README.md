# Сайт Ольги Борзенковой

https://borzenkova.ru — React + Vite + TypeScript, статический сайт без базы данных.

## Публикация

Любой коммит в `main` автоматически собирается, проверяется и выкладывается на
сервер (`.github/workflows/deploy.yml`), примерно 1–2 минуты. Pull Request только
проверяется; публикуется после слияния. Если сборка или проверка упала — на сайте
остаётся прошлая версия.

Правила для ИИ-агентов, которые редактируют сайт, — [AGENTS.md](AGENTS.md).

## Локально

```
npm ci
npm run dev      # http://localhost:5173
npm run check    # сборка + проверка, та же, что перед публикацией
```

Контакты на сайте ведут в Telegram. Форм сбора персональных данных нет и не должно быть.
